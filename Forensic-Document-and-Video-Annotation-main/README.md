# SVASI – Semantic-Driven Video Annotation for Forensic Intelligence

**A collaborative research and development project exploring semantic-driven video annotation and its applications in forensic investigation.**

## Overview

SVASI explores the use of Large Language Models (LLMs), semantic intelligence and information retrieval techniques to support video understanding and annotation.

The research considers how structured video information and semantic relationships can assist investigative workflows, including forensic analysis and Open-Source Intelligence (OSINT).

Rather than treating video annotation and forensic analysis as separate projects, SVASI explores video annotation as a core capability that can be applied to forensic and investigative scenarios.

## Research Focus

- Semantic-driven video annotation
- Large Language Model (LLM)-assisted information processing
- Retrieval-Augmented Generation (RAG) concepts
- Semantic relationships and knowledge representation
- Video understanding for forensic and investigative applications
- OSINT-oriented information exploration

## Frontend Features

The current React-based frontend prototype includes:

- Video URL input interface
- Multilingual selection interface (English, French, Hindi and Kannada)
- Open OSINT and private document-vault mode selection
- Semantic ontology visualisation workspace concept
- Conversational assistant interface
- Application status and orchestration interface

These features represent the frontend prototype and proposed interaction workflow. They should not be interpreted as evidence that all backend or AI processing capabilities are currently integrated.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Navigate to the frontend project directory:

```bash
cd Forensic-Document-and-Video-Annotation-main
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL displayed in the terminal.

### Production Build

```bash
npm run build
```

## Project Status

The repository currently contains the frontend prototype. Backend services, complete LLM/RAG processing pipelines and end-to-end forensic analysis functionality are not included in this frontend implementation.

The broader research and development work explores these capabilities as part of the SVASI architecture.

## Collaboration

SVASI is developed collaboratively, with contributions across research, technical development, UI/UX and frontend implementation.
