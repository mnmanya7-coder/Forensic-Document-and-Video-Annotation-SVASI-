# SVASI – Semantic-Driven Video Annotation for Forensic Intelligence

A collaborative research and development project exploring semantic-driven video annotation using Large Language Models (LLMs), semantic intelligence and information retrieval.

## About the Project

SVASI explores video annotation as a core capability that can support forensic and investigative workflows. Its research direction includes semantic understanding, intelligent information retrieval and potential applications in forensic document and video analysis.

## Current Implementation

This repository includes the React-based frontend prototype, featuring:

- Video URL input interface
- Multilingual selection
- OSINT and private document-vault workflow options
- Semantic ontology visualisation workspace concept
- Conversational assistant interface

**Note:** The current repository contains the frontend prototype. Backend and AI processing components are not included here.
